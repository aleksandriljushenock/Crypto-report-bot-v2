# Crypto Intelligence Platform v13 — Self Learning

## Что изменилось

v13 обучается на собственных завершённых прогнозах, но не меняет рабочую модель без проверки.

- временное разделение данных: старые 70% для обучения, новые 30% для проверки;
- versioned-модели: active / challenger / retired;
- ограничение изменения каждого веса;
- автоматическая калибровка диапазонов AI Score;
- Brier score, корреляция ранга, win rate и доходность Top 30%;
- No-Trade фильтры для повторяющихся убыточных условий;
- штраф No-Trade отображается в сигнале через aiNoTradePenalty;
- полная совместимость с базами v12;
- команда `/learn` запускает обучение и показывает диагностику.

## Безопасность обучения

Модель становится active только если на более новых данных одновременно:

1. Brier score улучшился минимум на LEARNING_MIN_IMPROVEMENT;
2. ранжирование не ухудшилось существенно;
3. средняя доходность лучших 30% сигналов не снизилась.

До накопления LEARNING_MIN_SAMPLES система продолжает использовать текущие веса.
