# Chronos Toggle + оценка частоты сигналов

Добавлены кнопки включения и выключения Chronos в AI-центре и панели состояния.
Runtime-переключатель хранится в data/automation_state.db. После полного рестарта Render используется значение CHRONOS_ENABLED из ENV.

Текущие строгие пороги:
- TRADE_MIN_SCORE=72
- TRADE_MIN_RR=2.0
- TRADE_MIN_PROBABILITY=65
- HEDGE_MIN_QUALITY=70
- HEDGE_MIN_EV_PCT=0.20
- QUALITY_MIN_SCORE=72
- до 16 ликвидных монет за проход

По 60 историческим snapshot-запускам из архива при выключенном Chronos:
- хотя бы один итоговый сигнал: 7 из 60 запусков (11.7%)
- на запуск: в среднем 0.12 итогового сигнала
- среди запусков с 18-22 монетами: 7 из 21 запусков (33.3%)
Оценка ориентировочная: snapshots относятся к прошлому рынку и отличаются по размеру выборки.
