# Exchange Status UX

Добавлен экран `🏦 Биржи` в разделе `📊 Аналитика`.

Экран показывает:
- настроенный порядок fallback-провайдеров из `TRADE_MARKET_PROVIDERS`;
- ONLINE / DEGRADED / COOLDOWN / НЕ ПРОВЕРЕНА;
- активный ping публичного ticker endpoint;
- задержку ответа;
- время последнего успешного запроса;
- последнюю ошибку провайдера;
- количество доступных бирж.

Кнопка `🔄 Проверить снова` выполняет лёгкую проверку BTCUSDT на каждой настроенной бирже.

SQL и новые ENV не требуются. По умолчанию используется `TRADE_MARKET_PROVIDERS=binance,bybit`.
