# v35 — уведомления отдельно для каждой стратегии

В экран каждой стратегии Strategy Lab добавлена кнопка `🔕 Уведомления: ВЫКЛ / 🔔 Уведомления: ВКЛ`.

## Поведение

- По умолчанию уведомления **выключены для каждой стратегии отдельно**.
- Включение одной стратегии не включает остальные.
- При включённой стратегии Telegram отправляет только actionable lifecycle: `READY → FILLED → CLOSED`.
- `WATCH`, `WAITING`, `NO_SETUP` и промежуточные кандидаты никогда не отправляются.
- Состояние переключателя хранится в `strategy_settings` Supabase и переживает redeploy.
- Если Supabase временно недоступен, безопасный fallback — OFF.

## Миграция

Новая SQL-миграция не требуется: используются существующая таблица `strategy_settings` и её upsert-механизм. Новые ключи автоматически seed-ятся при старте.

## Глобальные switches

`STRATEGY_LAB_NOTIFY_ENABLED`, `STRATEGY_LAB_NOTIFY_READY`, `STRATEGY_LAB_NOTIFY_FILLED`, `STRATEGY_LAB_NOTIFY_CLOSED` остаются master-switches. Даже если они включены, конкретная стратегия молчит, пока пользователь не включит уведомления в её меню.
