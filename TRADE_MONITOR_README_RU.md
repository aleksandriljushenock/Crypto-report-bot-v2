# Фоновый торговый монитор

Добавлено:
- ручной скан рынка: `/trade` или кнопка «🔍 Найти торговые входы»;
- фоновый мониторинг с интервалом 15 минут;
- уведомления только для `TRADE_CANDIDATE`;
- перспективные недавние листинги из локальной базы добавляются к ликвидному рынку Binance Futures;
- дедупликация одинаковых сигналов на 6 часов;
- история в `data/trade_signals.db`;
- команды `/monitor_on`, `/monitor_off`, `/monitor_status`, `/signals`.

## Установка
1. Скопировать файлы поверх текущего проекта, сохранив свой `.env`.
2. Активировать окружение: `.venv\Scripts\activate`
3. Установить зависимости: `pip install -r requirements.txt`
4. Проверить: `python -m compileall .`
5. Запустить: `python telegram_command_bot.py`

## Важно
Система не открывает сделки автоматически. Она формирует сценарии для ручного подтверждения. Рекомендуемый риск — 0.5–1% капитала на сделку.
