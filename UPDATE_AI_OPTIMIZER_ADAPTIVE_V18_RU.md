# AI Optimizer v17 + Adaptive Models v18

Объединённый релиз поверх Scanner State v16.

## v17 — AI Optimizer

- анализирует закрытые Paper Trading позиции из Supabase;
- ищет более прибыльные значения Probability, Quality, EV и R/R;
- не предлагает ослабление фильтров только по закрытым сделкам: для этого нет outcome отклонённых сигналов;
- сохраняет рекомендации в Supabase;
- стратегия не меняется автоматически — подтверждение делается кнопкой Telegram;
- при стабильно пустом сканере может рекомендовать расширить `TRADE_TOP_LIQUID_SYMBOLS` вместо ослабления качества;
- отслеживает стабильно слабые символы и предлагает снизить их приоритет как информационную рекомендацию.

## v18 — Adaptive Models

- обучает лёгкую logistic-модель на фактических Paper outcome;
- никаких pandas/sklearn/torch для этой модели — только Python, поэтому RAM почти не растёт;
- train/validation разделяются хронологически;
- новая модель становится Champion только если улучшает validation LogLoss относительно исходной probability;
- неудачная модель остаётся Candidate и не влияет на сигналы;
- Champion добавляет лишь небольшой голос (`ADAPTIVE_MODEL_BLEND_WEIGHT=0.20`) к существующему Hedge Engine;
- текущая стратегия остаётся основным источником решения;
- модель хранится в Supabase и переживает Railway redeploy.

## Supabase

Один раз выполнить:

`SUPABASE_AI_OPTIMIZER_ADAPTIVE_V18.sql`

Создаются:
- `ai_optimizer_runs`;
- `ai_optimizer_recommendations`;
- `adaptive_model_versions`.

## Рекомендуемый режим текущего эксперимента

До 50 Paper-сделок не применять рекомендации автоматически. Optimizer может собирать статистику, а Adaptive Model фактически начнёт обучение при `ADAPTIVE_MODEL_MIN_TRADES=40` и будет активирован только если пройдёт хронологическую проверку.
