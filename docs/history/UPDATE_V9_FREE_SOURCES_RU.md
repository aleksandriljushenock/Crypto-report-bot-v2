# Crypto Report Service v9 — Free Sources

## Что изменено

- NEWS_RSS_FEEDS и SMART_MONEY_FEEDS больше не обязательны.
- При пустых переменных автоматически используются встроенные публичные RSS-источники.
- Добавлен общий RSS/Atom-клиент с retry, таймаутами и XML-парсером.
- Новости дедуплицируются по источнику, заголовку и ссылке.
- Smart Money работает как бесплатный OSINT-сканер публичных упоминаний фондов, маркет-мейкеров, крупных держателей, inflow/outflow и whale-событий.
- Ошибки отдельных источников сохраняются в базе и не останавливают остальные сервисы.

## Настройка .env

Минимально достаточно:

```env
NEWS_ENGINE_ENABLED=true
NEWS_USE_DEFAULT_FEEDS=true
SMART_MONEY_ENABLED=true
SMART_MONEY_USE_DEFAULT_FEEDS=true
NEWS_RSS_FEEDS=
SMART_MONEY_FEEDS=
```

Пустые NEWS_RSS_FEEDS и SMART_MONEY_FEEDS означают: использовать встроенный список.
Если указать собственные URL, они полностью заменят встроенный список.

## Важное ограничение

Бесплатный Smart Money модуль анализирует публичные сообщения и новости. Он не притворяется Arkham/Nansen и не присваивает неизвестным адресам реальные названия организаций. Для точной разметки кошельков потребуется лицензированный источник.
