# Crypto Intelligence Platform v14 — Learning MAX

## Что изменилось

- обучение сразу по исходам 1h, 4h, 24h и 72h;
- больший вес недавним прогнозам с настраиваемым half-life;
- walk-forward validation вместо одного случайного разделения;
- отдельный финальный holdout, который оптимизатор не видит;
- модели-специалисты для bull/bear/range/breakout/accumulation/distribution;
- отдельные специалисты для LONG/SHORT при достаточном числе примеров;
- bounded random search для весов без внешних ML-библиотек;
- эмпирическая калибровка вероятности успеха;
- оценка неопределённости прогноза;
- обучение положительным комбинациям и No-Trade условиям;
- двухфакторные interaction rules;
- drift detector для смены характера рынка;
- champion/challenger и строгие условия автоматического продвижения;
- команды `/learn`, `/learnmax`, `/modelstatus`.

## Безопасность обучения

Новая модель не активируется только из-за хорошего результата на обучающем наборе. Она должна улучшить utility на отдельном хронологическом holdout и не ухудшить Brier Score, rank correlation и top-return сверх допустимых границ.

## Рекомендации

Для стабильного старта оставьте `LEARNING_MIN_SAMPLES=60`. Для полноценных режимных моделей желательно накопить 150–300 завершённых прогнозов.
