# Memory Safe v4

Сборка оптимизирована для Render 512 MB.

- Gunicorn: 1 worker / 1 thread.
- Тяжёлые фоновые задачи не выполняются одновременно.
- В LOW_MEMORY_MODE второстепенные автосервисы не стартуют по расписанию, но команды меню и ручные вызовы сохранены.
- Торговый скан: 1 worker, 16 ликвидных монет, пул AI-кандидатов 10.
- Chronos запускается в отдельном короткоживущем subprocess и полностью освобождает память после прогноза.
- Learning загружает не более 750 облачных строк и использует 40 итераций поиска.

Для 512 MB используйте параметры из `.env.example`.
Если всё равно появляется status 137, переключите `CHRONOS_MODE=remote` или временно `CHRONOS_ENABLED=false`.
