# Обновление: постоянное обучение и защита памяти

## Что исправлено
- v14 восстанавливает завершённые обучающие наблюдения из Supabase после рестарта Render.
- Активная модель восстанавливается из `model_registry`, если локальная SQLite база очищена.
- Каждый запуск обучения записывается в `training_runs`, включая `collecting-data`.
- Champion/challenger записываются в `model_registry`.
- Исправлен вывод `Нужно минимум: None`.
- Нормализованы направления `LONG_BIAS/SHORT_BIAS` в `LONG/SHORT` для специалистов.
- Торговые сканы защищены единым lock: два тяжёлых скана не выполняются одновременно.
- Уменьшены worker count, число инструментов и Gunicorn threads.
- Сырые рыночные снимки освобождаются до AI-ранжирования, добавлен принудительный GC и монитор RSS.

## Обязательный шаг
Откройте Supabase SQL Editor и выполните `SUPABASE_LEARNING_V14.sql`.
После этого redeploy Render. Переменные из `render.yaml` применятся автоматически для Blueprint; при ручном сервисе добавьте их в Environment.
