# Обновление: автоматический мониторинг v5

Добавлено:

- постоянный торговый монитор Binance Futures;
- торговый скан приоритетных монет из базы листингов и Early Discovery;
- параллельная загрузка рыночных данных;
- автоматический Early Discovery каждые 30 минут;
- автоматическое обновление базы листингов каждые 6 часов;
- автоматическое обновление результатов прогнозов каждые 3 часа;
- Telegram-уведомления по новым сильным проектам без повторов;
- дополнительный статус фоновых сервисов;
- дополнительные источники анонсов: BingX, CoinEx и LBank;
- настройки интервалов и порогов через `.env`.

## Установка

1. Скопируйте файлы поверх текущего проекта.
2. Не заменяйте свой `.env`.
3. Активируйте окружение и выполните:

```cmd
pip install -r requirements.txt
python -m compileall .
python telegram_command_bot.py
```

## Новые настройки `.env`

Скопируйте нужные строки из `.env.example`. Значения по умолчанию уже работают без добавления строк.

Кнопка `⚙️ Автосервисы` показывает состояние Early Discovery, обновления базы листингов и Outcome Tracker.

Торговый монитор по-прежнему включается кнопкой `▶️ Мониторинг` или командой `/monitor_on`.

Система не открывает сделки и не использует ключи торгового аккаунта. Все сигналы предназначены для ручной проверки.
