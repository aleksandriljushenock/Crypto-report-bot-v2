# Crypto Report Service v11 — Telegram UI

## Что изменилось

Главное меню Telegram-бота стало компактным и разделено на пять разделов:

- Анализ рынка
- Торговля
- AI Intelligence
- Портфель
- Система

Все прежние функции сохранены и доступны через подменю.

## Новые элементы

- компактный главный экран;
- строка состояния при `/start`;
- кнопка возврата в главное меню;
- отдельный раздел системного обслуживания;
- кнопка Health Check;
- кнопка Fear & Greed;
- справка по управлению портфелем;
- обновлённые названия Professional v8 → AI Центр.

## Обновление

1. Сохраните `.env` и папку `data`.
2. Распакуйте архив поверх текущей установки.
3. Запустите:

```cmd
.venv\Scripts\activate
python -m compileall .
python healthcheck.py
python telegram_command_bot.py
```

4. В Telegram отправьте `/start`, чтобы получить новое меню.
