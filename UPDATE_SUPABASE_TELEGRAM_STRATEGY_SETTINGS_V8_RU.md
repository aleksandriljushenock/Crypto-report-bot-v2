# Strategy Settings v8: Supabase + Telegram

## Что добавлено

- таблица `public.strategy_settings` для текущих параметров;
- таблица `public.strategy_settings_history` для истории изменений;
- загрузка настроек из Supabase при запуске бота;
- безопасный fallback на Render ENV;
- применение изменений без деплоя к следующим сканам;
- меню `Система -> Настройки стратегии`;
- редактирование фильтров, весов правил, размера позиции, recency и ширины скана;
- валидация типов и допустимых диапазонов;
- сброс отдельного параметра к значению по умолчанию.

## Перед деплоем

Запустить в Supabase SQL Editor файл:

`SUPABASE_STRATEGY_SETTINGS.sql`

После этого выполнить деплой. При первом старте бот заполнит таблицу значениями из Render ENV.

## Приоритет настроек

1. Supabase `strategy_settings`;
2. Render ENV;
3. значения по умолчанию в коде.

Изменение через Telegram записывается в Supabase и сразу зеркалируется в
`os.environ`, поэтому следующий торговый скан использует новое значение.

## Безопасность

RLS включён. Политики для `anon` и `authenticated` не создаются. Таблицы
доступны серверному боту через `SUPABASE_SERVICE_KEY`.
